Our Commitment

Mind Matters is committed to creating a website that is accessible to all users, including students with disabilities. Because this website focuses on mental health, it is especially important that everyone can easily access information, resources, and support without unnecessary barriers.

I believe that accessibility is an essential part of building a supportive and inclusive environment where all students feel welcome and understood.

Accessibility Features

The following features have been implemented to improve accessibility:

  • Semantic HTML structure using elements like header, nav, main, and section for better screen reader navigation
  • Clear heading hierarchy (h1, h2, h3) to organize content logically
  • Descriptive alt text for images to support screen readers
  • Color contrast designed to meet WCAG recommendations for readability
  • Responsive design that works on different screen sizes and devices
  • Accessible forms with properly labeled inputs and required fields
  • Simple navigation that is consistent across all pages

Testing

This website has been tested using the following tools and methods:

  • W3C HTML Validator
  • W3C CSS Validator
  • Manual testing of navigation links
  • Basic keyboard navigation testing
  • Responsive design testing using browser tools

These tests were used to identify errors, improve structure, and ensure the site is usable across different devices and browsers.

Known Limitations

While efforts have been made to improve accessibility, there are still some limitations:

  • Some pages may still be in progress and not fully optimized for accessibility
  • Advanced accessibility features (such as ARIA roles) have not yet been fully implemented
  • Some interactive features are basic and may be improved in future updates

I am continuously working to improve the accessibility of this website over time.

Feedback
